# 02 - 基础与通用组件设计规范

> **规范版本**：v1.0.0  
> **生效模块**：`src/react-app/styles/components.css`, `src/react-app/components/`  
> **核心目标**：统一全站原子组件与通用控件的结构、视觉样式、微交互反馈与无障碍体验

---

## 1. 按钮系统 (Button System)

按钮是用户与系统交互的核心触发器。所有按钮必须提供即时且明确的触觉/视觉微交互反馈。

```
                    ┌──────────────────────────────┐
                    │       按钮交互状态模型        │
                    └──────────────┬───────────────┘
                                   │
      ┌────────────────┬───────────┴───────────┬───────────────┐
      ▼                ▼                       ▼               ▼
┌───────────┐    ┌───────────┐           ┌───────────┐   ┌───────────┐
│  Default  │───▶│   Hover   │──────────▶│  Active   │───│ Disabled  │
│  常态基础 │    │ 浮起/加深 │           │ 按压微缩  │   │ 50%透明度 │
│           │    │ -1px / 光晕│          │ scale0.98 │   │ 禁止交互  │
└───────────┘    └───────────┘           └───────────┘   └───────────┘
```

### 1.1 按钮类型与使用场景

| 变体类名 (Variant) | 视觉特征 | CSS 实现要素 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **`btn-primary`** | 蓝紫渐变填充 + 品牌微光阴影 | `background: var(--gradient-primary); color: #fff; box-shadow: var(--shadow-primary);` | 页面首要行动点（提交表单、保存方案、立即预约） |
| **`btn-secondary`** | 浅灰中性底色 + 深灰文字 | `background: var(--color-bg-tertiary); color: var(--color-text-primary);` | 次要行动点（取消、重置、返回上一步） |
| **`btn-outline`** | 1px 品牌蓝边框 + 透明底 | `border: 1px solid var(--color-primary); color: var(--color-primary); background: transparent;` | 辅助操作（下载文档、规格预览、切换模式） |
| **`btn-ghost`** | 无边框透明底 + 悬停微灰 | `background: transparent; color: var(--color-text-secondary);` | 图标按钮、表格行操作按钮、关闭按钮 |

### 1.2 尺寸与热区规格

| 尺寸等级 | 类名 | 高度 | 内边距 (Padding) | 字号 / 字重 | 触控热区要求 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **小号 (sm)** | `.btn-sm` | 32px | `var(--spacing-1) var(--spacing-3)` (4px 12px) | `--text-xs` (12px) / Medium | 移动端增加伪元素保证 44px 热区 |
| **中号 (md / 默认)** | `.btn` | 40px | `var(--spacing-2) var(--spacing-4)` (8px 16px) | `--text-sm` (14px) / Medium | 满足桌面与移动端基准 |
| **大号 (lg)** | `.btn-lg` | 48px | `var(--spacing-3) var(--spacing-6)` (12px 24px) | `--text-base` (16px) / Medium | Hero 区域关键 CTA 按钮 |

### 1.3 交互动效与无障碍规范
- **按压反馈 (`.active-scale`)**：点击瞬间触发 `transform: scale(0.98)`，过渡耗时 80ms。
- **键盘焦点环 (`:focus-visible`)**：`outline: 2px solid var(--color-primary); outline-offset: 2px;`。
- **加载状态 (Loading)**：按钮文字隐去或保留，内联插入 `.spinner-sm`，并自动添加 `aria-busy="true"` 与 `disabled` 属性。

## 2. 表单与输入控件系统 (Form & Input System)

表单系统承担客户信息收集、预约信息录入、LED 屏体尺寸微调等高频操作，强调聚焦清晰度与即时容错反馈。

### 2.1 基础文本框与多行文本 (`.input`, `.textarea`)

```css
.input {
  width: 100%;
  padding: var(--spacing-3) var(--spacing-4);
  font-size: var(--text-base);
  color: var(--color-text-primary);
  background: var(--color-bg-primary);
  border: 1px solid var(--color-border-default);
  border-radius: var(--radius-lg);
  transition: all var(--transition-fast) var(--ease-default);
}

.input:focus {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px var(--color-primary-light);
}

.input-error {
  border-color: var(--color-error-500);
}

.input-error:focus {
  box-shadow: 0 0 0 3px var(--color-error-50);
}
```

### 2.2 专用输入控件规范

#### 1. 数字步进微调器 (`NumericStepper.tsx`)
- **应用场景**：LED 配置器中箱体数量（列/行）、屏体宽度/高度 (mm) 精确调节。
- **视觉结构**：
  ```
  ┌───────────────────────────────────────────────────────────┐
  │  [-] 减号按钮  │       1920 mm (可直接键盘编辑)      │  [+] 加号按钮  │
  └───────────────────────────────────────────────────────────┘
  ```
- **关键细节**：通过 CSS 类 `.numeric-stepper-input` 移除浏览器原生丑陋的 Spin Buttons；支持长按连续步进。

#### 2. 国家/区域选择器 (`FlagsSelect.css` / `react-flags-select`)
- **规范**：国旗 SVG 图标 + 英文/当地国名显示，内置搜索框，支持多国手机区号联动。

#### 3. 日期时间选择器 (`MyDatePicker.tsx` / `react-datepicker`)
- **规范**：基于 Apple 风格圆角（`--radius-xl`）与月历网格，禁用不可约时段，选中日期以 `--color-primary` 高亮胶囊展示。

## 3. 卡片与表面容器系统 (Card & Surfaces)

### 3.1 基础卡片 (`.card`) 与悬浮提升 (`.card-hover`, `.hover-lift`)
- **标准卡片结构**：
  ```
  ┌────────────────────────────────────────────────────────┐
  │ 卡片头部 (.card-header) : 标题 + 状态徽章 + 快捷操作   │
  ├────────────────────────────────────────────────────────┤
  │ 卡片主体 (.card-body)   : 主图、核心参数、文字描述     │
  ├────────────────────────────────────────────────────────┤
  │ 卡片底部 (.card-footer) : 次级信息、时间戳、CTA 按钮   │
  └────────────────────────────────────────────────────────┘
  ```
- **悬停提升动效**：
  ```css
  .card-hover:hover, .hover-lift:hover {
    box-shadow: var(--shadow-lg);
    transform: translateY(-4px);
    border-color: var(--color-primary-200);
  }
  ```

### 3.2 磁吸聚光灯卡片 (`SpotlightCard.tsx`)
- **原理**：监听鼠标在卡片上的 `(x, y)` 相对坐标，动态计算 Radial Gradient 径向微光跟随鼠标位置，带来苹果官网同级的微光交互体验。

## 4. 徽章与标签系统 (Badge System)

用于呈现产品认证、物料下载权限、订单状态等。

| 徽章类型 | CSS 类名 | 背景 Token | 文字 Token | 典型语义 |
| :--- | :--- | :--- | :--- | :--- |
| **品牌徽章** | `.badge-primary` | `--color-primary-light` | `--color-primary-700` | 推荐产品、新品标记 |
| **成功徽章** | `.badge-success` | `--color-success-50` | `--color-success-600` | 现货充足、已通过认证、正常运行 |
| **警告徽章** | `.badge-warning` | `--color-warning-50` | `--color-warning-600` | 需授权、即将过期、库存紧张 |
| **危险徽章** | `.badge-error` | `--color-error-50` | `--color-error-600` | 权限不足、下架停产、驳回 |
| **中性徽章** | `.badge-gray` | `--color-gray-100` | `--color-gray-600` | 规格尺寸、文件类型 (PDF/DWG) |
| **权限徽章** | `AccessLevelBadge` | 自定义根据 Level 映射 | 金/银/铜渐变 | VIP 专区用户角色与下载权限分级 |

## 5. 数据展示与反馈组件 (Feedback & Skeletons)

### 5.1 骨架屏微光动画 (`.skeleton`, `PageSkeleton.tsx`)
在数据加载与懒加载模块呈现占位骨架，消除白屏等待焦虑：

```css
.skeleton {
  background: linear-gradient(
    90deg,
    var(--color-gray-200) 25%,
    var(--color-gray-100) 50%,
    var(--color-gray-200) 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
  border-radius: var(--radius-md);
}

@keyframes shimmer {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
```

### 5.2 全局加载指示器 (Spinner) 与 500ms 延迟策略
- **加载器规范**：采用极简双色旋转圆环，提供 `.spinner-sm` (16px)、`.spinner` (20px)、`.spinner-lg` (32px)。
- **Apple 设计模式（Anti-Flicker）**：通过 `useDelayedLoading(loading, 500)`，当接口响应快于 500ms 时不展示 Spinner，防止短暂闪烁打扰用户。

### 5.3 吐司提示容器 (`ToastContainer.tsx` / `react-hot-toast`)
- **定位**：屏幕顶部居中 (`top-center`)，Z-Index 固定为 `1080`。
- **视觉风格**：深色/亮色玻璃拟态容器 + 语义图标（绿色对勾/红色感叹号），自动延时 3000ms 渐隐退出。

## 6. 导航与全局浮动系统 (Navigation & Dock)

### 6.1 顶部智能导航栏 (`AppHeader.tsx`)
1. **首屏沉浸态**：当滚动距离 `scrollY === 0` 时，背景保持全透明，文字呈现高对比白色/深色。
2. **滚动吸顶态 (`isScrolled`)**：滚动超过阈值时，自动平滑收缩高度至 64px，背景激活玻璃拟态（`.glass`），底部浮现细微分割阴影。
3. **滚动方向智能隐藏**：向下快速滚动时平滑上移移出视口，向上滚动时立即弹出恢复。
4. **二级分类悬浮抽屉**：鼠标悬停在“产品”或“方案”上时，向下平滑展开 Megamenu 大面板。

### 6.2 移动端全屏抽屉菜单 (`MobileMenu.tsx`)
- **过渡效果**：从右侧平滑滑入，附带高斯模糊遮罩层。
- **触控优化**：列表项最小高度 48px，支持手势滑动返回，内置语言切换与用户信息卡片。

### 6.3 底部悬浮胶囊栏 (`FloatingDock` / `FeedbackFloatingButton`)
- **形态**：屏幕底部居中胶囊形状浮动栏，集成了 AI 助手入口、快速反馈、返回顶部等功能。
- **紧凑模式 (`shouldUseCompactFloatingDock`)**：在案例详情页、LED 配置器等重度视口中，自动切换为紧凑小圆点，避免遮挡核心操作。
