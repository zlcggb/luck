# 05 - 动效、响应式与可访问性规范

> **规范版本**：v1.0.0  
> **生效模块**：全站通用样式、交互组件与布局容器  
> **核心目标**：保障在任何设备、网络条件与可访问性需求下，全站均具备顶级丝滑流畅度与包容性体验

---

## 1. 动效与微交互系统 (Motion System)

全站动效严格遵循 **“动效传达状态、层级与可用性，严禁纯装饰性动画”** 的核心原则。

```
                       ┌──────────────────────────────┐
                       │     动效时间与缓动分级模型    │
                       └──────────────┬───────────────┘
                                      │
         ┌────────────────────────────┼────────────────────────────┐
         ▼                            ▼                            ▼
┌──────────────────┐         ┌──────────────────┐         ┌──────────────────┐
│ 1. 微交互与点击反馈 │         │ 2. 卡片悬浮与面板展开│         │ 3. 页面转场与Hero │
│ • 持续时间 80~150ms │         │ • 持续时间 200~300ms │         │ • 持续时间 300~500ms │
│ • 按钮缩放/颜色变化 │         │ • 抽屉滑入/模态框弹出 │         │ • 视差滚动/画廊旋转 │
│ • cubic-bezier(out)│         │ • cubic-bezier(ease)│         │ • 流畅物理阻尼感    │
└──────────────────┘         └──────────────────┘         └──────────────────┘
```

### 1.1 缓动函数标准 (Timing Functions)

```css
/* 默认通用缓动 — 自然平滑 */
--ease-default: cubic-bezier(0.4, 0, 0.2, 1);

/* 入场缓动 — 快速响应并缓刹（用于弹窗、下拉菜单） */
--ease-out: cubic-bezier(0, 0, 0.2, 1);

/* 出场缓动 — 快速加速退出（用于关闭弹窗、提示消失） */
--ease-in: cubic-bezier(0.4, 0, 1, 1);

/* 弹性回弹 — 带有轻微物理弹性的趣味交互（用于微小徽章、喜欢/收藏按动） */
--ease-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

### 1.2 交错入场编排 (Staggered Animation Sequence)
页面加载或列表批量呈现时，子元素应添加阶梯延迟，避免大面积元素同时生硬跳出：

```css
/* 示例：列表卡片按顺序交错滑入 */
.stagger-item:nth-child(1) { animation-delay: 50ms; }
.stagger-item:nth-child(2) { animation-delay: 100ms; }
.stagger-item:nth-child(3) { animation-delay: 150ms; }
.stagger-item:nth-child(4) { animation-delay: 200ms; }
```

### 1.3 滚动显现动效 (`ScrollReveal.tsx`)
页面下方内容在进入视口前保持 `opacity: 0; transform: translateY(30px);`，当 `IntersectionObserver` 监测到进入视口 15% 时，立即添加 `.revealed` 类，触发 600ms 丝滑平移显现。

### 1.4 减少动画偏好适配 (Reduced Motion)
系统必须无条件遵守用户的系统级无障碍设置：

```css
@media (prefers-reduced-motion: reduce) {
  :root {
    --transition-fast: 0ms;
    --transition-default: 0ms;
    --transition-slow: 0ms;
    --transition-slower: 0ms;
  }
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## 2. 全端响应式与移动端适配 (Responsive Strategy)

### 2.1 响应式断点标尺

| 设备大类 | 断点范围 | 布局特征与适配策略 |
| :--- | :--- | :--- |
| **手机竖屏 (Mobile)** | `< 640px` (`sm`) | 顶部 Header 折叠为汉堡菜单，所有横向栅格坍缩为单列，底部显示悬浮工具球 |
| **手机横屏/小平板 (Tablet sm)** | `640px ~ 768px` (`md`) | 2 列流式卡片网格，弹窗宽度自适应铺满 90% |
| **标准平板/小笔电 (Tablet lg)** | `768px ~ 1024px` (`lg`) | 导航栏展开完整菜单，LED 配置器采用上下堆叠视口 |
| **标准桌面 (Desktop)** | `1024px ~ 1440px` (`xl`~`8xl`) | 标准版心（1440px），LED 配置器左中右完整三栏展开 |
| **超宽屏/4K会议屏 (Ultra-Wide)** | `> 1440px` (`9xl`) | 沉浸式 3D 展厅最大宽度拓宽至 1600px，背景延展 |

### 2.2 移动端安全区域适配 (Safe Area Insets)
在 iPhone 全面屏（带灵动岛/刘海）及底部横条设备上，所有浮动元素必须使用安全区域类名：

```css
.pt-safe-top {
  padding-top: env(safe-area-inset-top);
}
.pb-safe-bottom {
  padding-bottom: env(safe-area-inset-bottom);
}
.pl-safe-left {
  padding-left: env(safe-area-inset-left);
}
.pr-safe-right {
  padding-right: env(safe-area-inset-right);
}
```

### 2.3 触控优化与手势防冲突
- **触控滚动优化**：在所有横向滑动轨道与抽屉面板上添加 `-webkit-overflow-scrolling: touch; overscroll-behavior: contain;`。
- **点击延迟消除**：所有可点击元素添加 `touch-action: manipulation;`。

## 3. 无障碍性规范 (Accessibility - WCAG 2.1 AA)

### 3.1 颜色对比度标准 (Contrast Ratio)
- **常规正文与按钮文字**：与背景的对比度必须 **≥ 4.5:1**。
- **大号标题（≥ 18pt 或 ≥ 14pt 粗体）与大图标**：对比度必须 **≥ 3.0:1**。
- **辅助说明弱化文字**：必须 **≥ 3.0:1**，严禁在浅灰底上使用几乎不可见的浅淡字色。

### 3.2 严禁使用 Emoji 代替功能图标
| ❌ 严禁使用 | ✅ 规范要求 | 原因说明 |
| :--- | :--- | :--- |
| 使用 Emoji（🔍 ⚙️ 📥 📅）做导航与设置图标 | 统一引入 `lucide-react` 或 `@phosphor-icons/react` SVG 图标 | Emoji 在 iOS/Android/Windows 渲染差异极大，且无法通过 CSS Token 统一控制颜色与线宽 |

### 3.3 键盘导航与焦点管理
- **Tab 顺序可达**：页面所有交互控件（链接、按钮、输入框、复选框）必须可以通过键盘 `Tab` 键依次聚焦。
- **Focus Ring 焦点环可见性**：必须保留 `:focus-visible` 轮廓高亮，禁止 `outline: none` 后不提供替代高亮态。

## 4. UI/UX 交付前终极核查清单 (Deliverable Checklist)

在任何新功能、新页面或 UI 重构合并前，必须逐一验证以下 20 项指标：

### 4.1 视觉质量 (Visual Quality)
- [ ] 1. 全站无任何 Emoji 作为功能/导航图标，全部采用统一风格的矢量 SVG 图标。
- [ ] 2. 所有图标大小严格使用 Token 阶梯（16px / 20px / 24px / 32px），描边宽度一致（1.5px 或 2px）。
- [ ] 3. 颜色完全由 CSS 自定义属性或 Tailwind 规范类驱动，无任意手写的离散 HEX 色值。
- [ ] 4. 图片资源有加载中占位与失败兜底图，所有图片带有明确的宽高比或 `aspect-ratio`。

### 4.2 交互与微动效 (Interactions & Micro-motion)
- [ ] 5. 所有按钮与可点击卡片在鼠标悬停时有明确反馈，在按压瞬间具备微缩反馈（80ms）。
- [ ] 6. 移动端所有交互热区不低于 44×44px。
- [ ] 7. 动画耗时控制在 150ms ~ 300ms 之间，无拖沓滞涩感。
- [ ] 8. 禁用状态控件（`disabled`）视觉明显变淡且不可触发点击。
- [ ] 9. 数据加载采用 500ms 防闪烁延迟机制，避免极快接口出现晃眼加载框。

### 4.3 明暗模式与对比度 (Dark Mode & Contrast)
- [ ] 10. 正文文字对比度在亮色与暗色两种模式下均达到 ≥ 4.5:1。
- [ ] 11. 边框与分割线在深色模式下清晰可辨，无糊死黑屏现象。
- [ ] 12. 模态框遮罩层具备高斯模糊（`blur(8px)`）并能有效隔离前景与背景。

### 4.4 布局与多端适配 (Layout & Multi-device)
- [ ] 13. 页面在 iPhone（375px）、iPad（768px）、MacBook（1440px）与宽屏上均无水平溢出或排版破损。
- [ ] 14. 页面各层级边距严格遵循 4dp/8dp 比例尺系统。
- [ ] 15. 长段正文最大宽度受到 `65ch` 限制，保障舒适阅读体验。
- [ ] 16. 移动端适配了底部与顶部 Safe Area 安全区域。

### 4.5 无障碍与语义化 (A11y & Semantics)
- [ ] 17. 弹窗支持按 `ESC` 键退出，且弹窗开启时底层页面锁定滚动。
- [ ] 18. 所有表单控件具备清晰的 Label、Placeholder 与聚焦焦点环。
- [ ] 19. 表格数值类列应用了等宽数字类名（`.tabular-nums`）。
- [ ] 20. 完整支持系统的 `prefers-reduced-motion` 减少动效设置。
