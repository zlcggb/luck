> **规范版本**：v1.0.0

> **设计基调**：Apple 极简精致设计语言（Minimalist Refined） × 高端光显科技工业风

## 1. 美学定位与设计哲学

洲明科技（Unilumin）VIP 专区面向全球专业客户、高端工程商及内部专家，其前端视觉与交互体验建立在两大支柱之上：

```
       ┌────────────────────────────────────────────────────────┐
       │               Unilumin VIP Web 设计哲学               │
       └──────────────────────────┬─────────────────────────────┘
                                  │
         ┌────────────────────────┴─────────────────────────┐
         ▼                                                  ▼
┌─────────────────────────────────┐       ┌──────────────────────────────────┐
│   Apple 极简精致设计语言        │       │      高端光显科技工业风          │
│ • 微对比度与大面积克制留白       │       │ • 深邃星空与光影渐变 (Glow)     │
│ • 流体排版 (Fluid Typography)   │       │ • 3D 视口与多面空间拓扑渲染      │
│ • 物理级玻璃拟态 (Backdrop Blur)│       │ • 高精度工程图表与等宽数字对齐   │
│ • 丝滑贝塞尔缓动与微反馈        │       │ • 严格的工业级状态指示与安全确认 │
└─────────────────────────────────┘       └──────────────────────────────────┘
```

### 核心设计原则
1. **内容驱动（Content First）**：UI 控件退居幕后，将视觉焦点让位给 LED 屏幕显示效果、走线图纸、案例高清图集与工程参数。
2. **确定性与高精度（Precision & Determinism）**：参数微调、价格计算、走线连线毫厘不差，排版全面采用等宽数字（`tabular-nums`），保障工程数据的严谨。
3. **呼吸感与层级节奏（Rhythm & Whitespace）**：严格遵循 4/8dp 栅格体系，以留白作为信息区块分割的主力，避免粗暴的实线分割。
4. **多模态合规与包容性（Compliance & Accessibility）**：自顶向下融入 GDPR 隐私合规、暗色自适应和 WCAG 2.1 AA 级对比度。

## 3. 流体排版系统 (Fluid Typography)

为了保证在大尺寸 4K 会议屏、宽屏工作站、笔记本以及移动端 iPad/iPhone 上获得毫无断点撕裂感的排版体验，全站排版升级为基于 `clamp(min, preferred, max)` 的流体排版模型。

### 3.1 字体族规范 (Font Family)

```css
/* 系统默认无衬线字体栈 — 首选 Apple SF Pro 与苹方 */
--font-sans: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'SF Pro Text', 
             'Helvetica Neue', 'PingFang SC', 'Microsoft YaHei', sans-serif;

/* 等宽字体栈 — 应用于 LED 走线代码、工程数值、坐标与参数 */
--font-mono: 'SF Mono', 'Fira Code', 'Consolas', 'Monaco', monospace;
```

### 3.2 字阶标尺 (Fluid Scale Matrix)

| 级别 | CSS Variable | 计算公式 (Viewport: 375px ~ 1440px) | 渲染范围 | 字重/行高 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **6XL** | `--text-6xl` | `clamp(2.75rem, 4vw + 1rem, 3.75rem)` | 44px ~ 60px | Bold / 1.1 | 首页巨幅 Hero 标语 |
| **5XL** | `--text-5xl` | `clamp(2.25rem, 3vw + 1rem, 3.00rem)` | 36px ~ 48px | Light(300) / 1.2 | 大栏目主标题 (Heading 1) |
| **4XL** | `--text-4xl` | `clamp(1.875rem, 2vw + 1rem, 2.25rem)` | 30px ~ 36px | Semibold(600) / 1.2 | 模块/页面主标题 (Heading 2) |
| **3XL** | `--text-3xl` | `clamp(1.5rem, 1.5vw + 0.9rem, 1.875rem)` | 24px ~ 30px | Semibold(600) / 1.35 | 弹窗大标题、重点卡片标题 |
| **2XL** | `--text-2xl` | `clamp(1.25rem, 1vw + 0.9rem, 1.50rem)` | 20px ~ 24px | Semibold(600) / 1.35 | 区域小节标题 (Heading 3) |
| **XL** | `--text-xl` | `clamp(1.125rem, 0.6vw + 0.95rem, 1.25rem)` | 18px ~ 20px | Medium(500) / 1.35 | 卡片标题、导航项 (Heading 4) |
| **LG** | `--text-lg` | `clamp(1.0625rem, 0.5vw + 0.9rem, 1.125rem)` | 17px ~ 18px | Regular(400) / 1.625 | 前言导语、强调段落 (Body lg) |
| **BASE** | `--text-base` | `1rem` (固定基准) | 16px | Regular(400) / 1.5 | 标准正文、表单输入框文本 |
| **SM** | `--text-sm` | `0.875rem` (固定基准) | 14px | Regular(400) / 1.5 | 按钮文字、表格正文、辅助说明 |
| **XS** | `--text-xs` | `0.75rem` (固定基准) | 12px | Regular / Semibold | 徽章、脚注、Overline 标签 |

### 3.3 阅读行宽与数字排版
- **黄金阅读容器 (`.prose`)**：长文本最大宽度严格限制在 `65ch`（约 65 个英文字符或 35 个汉字），避免眼球过宽摆动导致疲劳。
- **等宽数字优化 (`.tabular-nums`)**：在所有价格、规格数据、BOM 清单、倒计时、坐标显示中使用 `font-variant-numeric: tabular-nums`，确保垂直列对齐不抖动。

## 4. 间距与网格系统 (Spacing & Layout)

全站严格遵循 **4dp / 8dp 节奏系统**，确保所有内边距（padding）、外边距（margin）和组件对齐具备一致的节奏感。

### 4.1 间距标尺

--spacing-3: 0.75rem;   /* 12px - 控件标准内边距 */
--spacing-4: 1rem;      /* 16px - 基础网格间距、卡片内边距 */
--spacing-5: 1.25rem;   /* 20px - 表单行间距 */
--spacing-6: 1.5rem;    /* 24px - 卡片间距、区块内边距 */
--spacing-8: 2rem;      /* 32px - 模块小节间距 */
--spacing-10: 2.5rem;   /* 40px - 弹窗内容与底部间距 */

## 6. Z-Index 层级管理规范

为杜绝组件层叠混乱（例如浮动按钮遮挡弹窗、下拉菜单被图表遮挡等问题），全站采用强约束的 Z-Index 标尺：

```
层级高度 (Z-Index)
   ▲
1080 ┼── ToastContainer (全局吐司消息条)
1070 ┼── Tooltip (提示文字气泡)
1060 ┼── Popover / Floating Menu (弹出浮层)
1050 ┼── Modal Window (弹窗对话框主体)
1040 ┼── Modal Backdrop (弹窗高斯模糊遮罩层)
1030 ┼── Fixed Header & Floating Dock (吸顶导航栏、底部悬浮胶囊栏)
1020 ┼── Sticky Table Headers / Sidebars (粘性表格头、侧边栏)
1000 ┼── Dropdown Menus (下拉选择菜单)
   1 ┼── Normal Content (普通页面内容)
   0 ┼── Background / Stars Canvas (星空画布底纹)
```

## 7. 玻璃拟态 (Glassmorphism) 标准规范

作为 Apple 设计风格的重要承载，全站玻璃拟态统一使用标准配方，禁止随意手写不透明度：

```css
/* 标准浅色玻璃拟态 — 用于 Header、浮动 Dock、卡片面板 */
.glass {
  background: rgba(255, 255, 255, 0.8);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.3);
}

/* 深色玻璃拟态 — 用于 3D 展厅、沉浸式播放器浮层 */
.glass-dark {
  background: rgba(15, 23, 42, 0.75);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.1);
}
```
