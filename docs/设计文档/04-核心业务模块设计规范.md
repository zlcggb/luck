# 04 - 核心业务模块设计规范

> **规范版本**：v1.0.0  
> **生效模块**：`src/react-app/home/`, `src/react-app/products/`, `src/react-app/download/`, `src/react-app/appointment/`, `src/react-app/trainingcenter/`, `src/react-app/forms/`, `src/react-app/admin/`, `src/react-app/page-agent/`  
> **核心目标**：解构全站八大业务系统的架构布局、交互流程、状态机与输出规范

## 1. 首页与沉浸式品牌体验 (HomePage)

首页是全球客户进入 VIP 专区的首要门户，设计上融合了电影级视差滚动与 3D 交互展厅。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 电影级视差滚动 Hero (ScrollCinematicHero)                          │
│    • 全屏沉浸视频背景 ──(滚动渐进缩小并呈现圆角)──▶ 60vw 居中聚光灯卡片 │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 3D 环形展厅画廊 (CircularGallery / RollingGallery)                  │
│    • OGL / Three.js 驱动的 360° 环形产品卡片滑动，支持惯性拖拽与点击聚焦 │
├────────────────────────────────────────────────────────────────────────┤
│ 3. 核心工具与解决方案矩阵 (ToolsOverview)                              │
│    • LED 配置器、全球展厅预约、案例选集、培训认证 4 大入口的微光磁吸卡片 │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.1 核心组件规范
- **`ScrollCinematicHero.tsx`**：
  - 初始全屏视频（`100vw × 100vh` 无圆角）。
  - 监听页面滚动驱动 CSS 变量变换：视频平滑缩放至 `60vw × 60vh`，外层附带 `border-radius: 1rem` 与 `--shadow-2xl`，同时大标题文字透明度与位移交错入场。
- **`CircularGallery.tsx`**：
  - 基于 WebGL/OGL 实现的 3D 圆柱形曲面轮播。
  - 支持鼠标悬停高亮、鼠标水平拖拽旋转（带物理阻尼感）与点击单品查看详情。

## 2. LED 智能配置器系统 (LED Configurator)

LED 智能配置器是 VIP 平台最核心的高复杂度工程设计系统，支持单面屏/多面屏（折角屏、L型屏、U型弧形屏）参数实时解算、3D 渲染与走线拓扑生成。

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         LED 智能配置器系统布局架构                        │
├───────────────────────┬──────────────────────────┬───────────────────────┤
│ 左侧参数配置面板      │ 中央 2D/3D 视口画布      │ 右侧实时 BOM 与规格   │
│ (ConfigurationPanel)  │ (DisplayWallPreview)     │ (SpecificationsPanel) │
│ • 产品系列/点间距选择  │ • WebGL 3D 真实比例渲染  │ • 屏幕总物理尺寸 (mm) │
│ • 箱体行列数量步进器  │ • 多面屏展开与折角视图   │ • 总像素分辨率 & 比例 │
│ • 弧度/曲率 (Curvature)│ • 信号走线 (Signal) 拓扑 │ • 峰值功耗 / 平均功耗 │
│ • 安装方式与维护结构  │ • 供电走线 (Power) 拓扑  │ • 动态预算与价格计算  │
├───────────────────────┴──────────────────────────┴───────────────────────┤
│ 底部/悬浮工具栏 (MultiFaceFloatingToolbar) : 预设选择 / 视口切换 / 导出  │
└──────────────────────────────────────────────────────────────────────────┘
```

### 2.1 核心功能与交互规范
1. **多面屏空间拓扑 (`multi-face/`)**：
   - 支持添加多个 Wall Face（正面、左折面、右折面、顶部天幕）。
   - 提供顶视图 (`MultiFaceTopPreview`) 与展开正视图 (`MultiFaceFrontPreview`)。
2. **走线拓扑图引擎 (`PowerWiringDiagram` & `SignalWiringDiagram`)**：
   - 信号走线：自动根据控制器主控口带载上限（如单网口 65 万点）规划蛇形走线，不同网口以不同色谱高亮区分。
   - 供电走线：根据单回路最大承载功率计算回路数，生成规范配电拓扑。
3. **多格式工程导出引擎**：
   - **Excel 报价单 (`ExcelQuotationExport.tsx`)**：利用 `ExcelJS` 自动生成包含封面、BOM 明细、电气参数与商务条款的标准 `.xlsx` 报价表。
   - **工程数据持久化 (`SaveProjectDialog` / `LoadProjectDialog`)**：支持云端 Supabase 数据库存储与本地 JSON 工程文件导入导出。

## 4. 全球展厅预约与服务网点 (Appointment & Service Points)

支持全球客户在线探索洲明科技分布于全球数十个国家和地区的线下展厅，并完成无缝预约。

### 4.1 地图与日历联动架构
- **地图视图 (`LeafletMap.tsx` / `react-leaflet` / `MapLibre GL`)**：
  - 全球地图平滑缩放与聚合打点（Marker Cluster）。
  - 点击国家/展厅点位，地图平滑飞越（FlyTo）至目标城市，下方卡片联动高亮。
- **日历预约面板 (`CustomCalendar.scss` / `FullCalendar`)**：
  - 自动读取展厅开放日与时区信息，置灰不可约日期。
  - 选择具体时间段（上午 10:00-12:00、下午 14:00-16:00）。
  - 填写随行人数、参观目的与产品偏好后，通过 `appointmentEmailService.ts` 自动触发双向确认邮件通知。

## 6. 动态表单引擎 (Dynamic Forms)

支持后台配置式生成各种复杂的商务合作、活动报名、满意度调研等公开表单（`forms/PublicFormPage.tsx`）。

### 6.1 功能特性
1. **Schema 驱动渲染**：支持短文本、长文本、单选、多选、下拉选择、文件上传、评分条、矩阵单选题等控件。
2. **客户端与服务端双重校验**：基于 `formSchema.ts` 严格校验字段必填与正则表达式。
3. **提交凭证收据 (`responseReceipt.ts`)**：用户提交后即时生成具备专属流水号、提交时间戳和内容摘要的电子回执，支持打印和保存图片。

## 7. 后台管理系统 (Admin Portal)

面向管理员的集中式运营与数据维护中心（`src/react-app/admin/`）。

- **架构特点**：基于模块化解耦架构，包含用户管理、产品数据、营销案例、展厅预约、动态表单配置、工单反馈与审计日志。
- **交互规范**：
  - 左侧自适应折叠导航栏。
  - 右侧统一标准数据表格（支持列宽拖拽、多字段组合筛选、批量导出与批量状态变更）。
  - 数据编辑采用统一侧边滑出抽屉或标准居中模态框，保证操作上下文不丢失。

## 8. AI Page Agent 智能助手系统 (`page-agent/`)

平台内置了新一代智能 Web 页面助手，通过悬浮控制栏与用户进行自然语言交互，并能自主辅助完成跨模块跳转与表单辅助填报。

- **`PageAgentBar.tsx`**：底部极简交互条，支持语音/文字输入。
- **`pageAgentCursor.ts`**：在执行自动操作时，屏幕上浮现平滑光标轨迹，引导用户理解 Agent 的动作意图。
- **安全沙箱机制 (`pageAgentSafety.ts`)**：对删除、修改密码、大额订单提交等高危操作强制弹出人工二次确认气泡。
