# 03 - 弹窗与对话框设计规范

> **规范版本**：v1.0.0  
> **生效模块**：`src/react-app/components/*Modal.tsx`, `src/react-app/components/*Dialog.tsx`, 业务模块弹窗  
> **设计基准**：Apple 极简模态交互范式 × 高斯模糊遮罩 × 确定性操作流程

## 1. 弹窗分级体系与交互范式

VIP Unilumin Web 平台中包含丰富的数据配置、合规授权和业务操作流程，系统将弹窗严格划分为 5 种层级与形态：

```
                               ┌────────────────────────────────┐
                               │       弹窗组件交互分级模型      │
                               └───────────────┬────────────────┘
                                               │
         ┌───────────────────┬─────────────────┴───────────────────┬───────────────────┐
         ▼                   ▼                                     ▼                   ▼
┌─────────────────┐ ┌─────────────────┐                   ┌─────────────────┐ ┌─────────────────┐
│ 1. 操作确认对话框 │ │ 2. 核心功能模态框 │                   │  3. 侧边抽屉面板 │ │ 4. 命令搜索面板 │
│ (Confirm Dialog)│ │ (Standard Modal)│                   │ (Drawer Panel)  │ │(Command Palette)│
│ • 危险操作拦截   │ │ • 表单填写、规格对比│                   │ • 工单追踪、选集车│ │ • 全局快速寻址  │
│ • 宽度 400~480px│ │ • 宽度 560~960px│                   │ • 宽度 480~640px│ │ • 快捷键 ⌘K 唤出 │
└─────────────────┘ └─────────────────┘                   └─────────────────┘ └─────────────────┘
```

### 1.1 弹窗形态对照表

| 弹窗形态 | 宽度规范 (Max-Width) | 出现方式 | 适用场景 | 典型组件 |
| :--- | :--- | :--- | :--- | :--- |
| **确认对话框 (Dialog)** | `400px ~ 480px` | 居中弹出微缩放 | 退出确认、删除拦截、工具跳转提醒 | `ConfirmDialog`, `ToolsConfirmDialog` |
| **标准模态框 (Modal)** | `560px ~ 720px` | 居中弹出微缩放 | 登录注册、合规授权、工单反馈、外设选型 | `FeedbackModal`, `AgeVerificationModal` |
| **超宽/全景模态框 (Wide)**| `800px ~ 1100px` | 居中大视口 | 产品多维规格对比、工程文档批量下载 | `ProductSpecificationModal`, `DocumentFilesModal` |
| **侧边抽屉 (Drawer)** | `480px ~ 640px` (自右侧滑出) | 右侧水平滑入 | 我的工单进度面板、PPT 选集清单管理 | `MyFeedbacksPanel`, `SelectedCaseDeckPage` |
| **命令面板 (Palette)** | `640px` (顶部偏上居中) | 顶部居中下落 | 全站全局智能搜索与功能导航 | `SmartSearch` |

## 2. 遮罩层与微交互动效规范

### 2.1 遮罩层标准 (Backdrop)
- **视觉属性**：
  ```css
  .modal-backdrop {
    position: fixed;
    inset: 0;
    z-index: var(--z-modal-backdrop); /* 1040 */
    background: rgba(0, 0, 0, 0.45);
    backdrop-filter: blur(8px);
    -webkit-backdrop-filter: blur(8px);
  }
  ```
- **滚动穿透锁定**：弹窗激活时，必须自动向 `document.body` 添加 `overflow: hidden;`，移动端增加 `touch-action: none;`，防止底层页面意外滑动。

### 2.2 弹窗主体入场/退场动画
- **入场动画**：从 `opacity: 0; transform: scale(0.95) translateY(10px);` 平滑过渡至 `opacity: 1; transform: scale(1) translateY(0);`，时长 **200ms**，缓动函数 `var(--ease-out)`。
- **退场动画**：150ms 迅速淡出并缩小。

### 2.3 关闭与防呆逻辑
1. **ESC 按键支持**：所有非强制阻塞型弹窗必须支持按下键盘 `ESC` 键关闭。
2. **点击遮罩关闭**：默认支持点击外部空白遮罩关闭；但对于**包含用户已填写数据的表单弹窗**（如 Feedback、LED 保存方案），必须弹出离开防丢确认。
3. **右上角标准关闭按钮**：统一尺寸 36×36px，内嵌 Lucide `X` 图标，悬停时浅灰圆角底色反馈。

## 3. 全局与安全合规弹窗体系

```
┌────────────────────────────────────────────────────────────────────────┐
│                        GDPR & 隐私安全弹窗矩阵                         │
├──────────────────────────┬─────────────────────────────────────────────┤
│ EnhancedCookieConsent    │ Cookie 细粒度分级授权（必要/分析/营销功能） │
│ AgeVerificationModal     │ 欧洲与跨国合规年龄准入确认 (16+/18+)        │
│ PrivacyModal             │ 洲明科技隐私合规条款与国际数据传输声明     │
│ DataRightsRequestModal   │ GDPR 数据权利行使：导出数据/修改/注销与删除 │
└──────────────────────────┴─────────────────────────────────────────────┘
```

### 3.1 Cookie 隐私偏好中心 (`EnhancedCookieConsent.tsx`)
- **形态**：屏幕底部居中大圆角浮动卡片（`.glass` 风格）。
- **交互功能**：
  - 一级视图：提供“全部接受”、“仅接受必要”、“自定义偏好”三大按钮。
  - 二级视图：抽屉式展开【必要 Cookie】、【性能与分析 Cookie】、【功能与营销 Cookie】的独立 Switch 开关，说明保留时长与用途。

### 3.2 GDPR 数据权利请求模态框 (`DataRightsRequestModal.tsx`)
- **包含完整 4 步向导式流程**：
  1. 验证用户身份（邮箱与授权令牌）
  2. 选择行使权利类型（数据访问下载、更正错误数据、限制处理、彻底擦除删除账号）
  3. 风险提示与影响范围说明
  4. 提交凭证与工单号生成

### 3.3 问题反馈与工单追踪系统
1. **反馈提交弹窗 (`FeedbackModal.tsx`)**：
   - 支持问题分类（UI缺陷、功能故障、LED配置建议、商务咨询）
   - 内置问题严重程度等级（Low / Medium / High / Critical）
   - 支持截图/图片拖拽上传与即时缩略图预览
2. **工单追踪抽屉 (`MyFeedbacksPanel.tsx`)**：
   - 侧边滑出面板，呈现历史反馈时间线、客服官方回复、处理状态（待处理、处理中、已解决、已关闭）。

### 3.4 全局命令式搜索面板 (`SmartSearch.tsx`)
- **快捷键触发**：支持全局监听 `⌘ + K` (Mac) 或 `Ctrl + K` (Windows) 唤起。
- **即时检索**：输入关键字即时模糊匹配产品系列、LED 工具、技术文档、展厅网点和培训课程，支持键盘上下箭头高亮与 Enter 直接跳转。

## 4. 业务场景专用弹窗规范

### 4.1 产品多维参数对比弹窗 (`ProductSpecificationModal.tsx`)
- **视口规格**：`max-w-5xl` (1024px)，高度自适应但限制 `max-h-[85vh]`，内置平滑滚动区。
- **结构划分**：
  - 顶部：产品型号名、像素间距（Pixel Pitch）胶囊、下载 PDF 规格书快捷入口。
  - 主体：两栏/三栏参数表格，包含光学参数（亮度、刷新率、对比度）、电气参数（最大功耗、平均功耗）、物理机械参数（箱体尺寸、重量、防护等级 IP 等）。
  - 交互：支持参数高亮对比与差异项仅显示。

### 4.2 LED 配置器工程管理弹窗
1. **保存工程对话框 (`SaveProjectDialog.tsx`)**：
   - 输入项目名称、客户名称、备注说明。
   - 提供“保存到云端项目库”与“导出本地 `.json` 方案文件”双选项。
2. **载入工程对话框 (`LoadProjectDialog.tsx`)**：
   - 云端历史工程列表（含缩略图、创建时间、总箱体数、总分辨率）。
   - 支持拖拽本地工程文件一键解析还原。
3. **控制系统与外设选型弹窗 (`ControlSystemDialog.tsx`)**：
   - 自动根据当前总分辨率计算所需主控发送卡带载口数。
   - 推荐配电箱功率（KVA）、视频处理器与备用辅料清单，支持一键加入 BOM。
4. **Excel 报价单导出设置 (`ExcelQuotationExport.tsx`)**：
   - 选择报价币种（USD / EUR / CNY）、客户抬头、质保年限、是否含税、运费明细，一键调用 ExcelJS 导出专业商务报价表格。

### 4.3 营销素材多模态预览弹窗 (`PreviewModal.tsx`)
- **功能**：点击物料或案例图集时弹出。
- **支持格式**：
  - 高清图片：支持滚轮缩放、拖拽平移、全屏展示。
  - 视频播放：内嵌无缝 React Player，支持倍速播放与音量调节。
  - PDF 在线预览：利用 `pdfjs-dist` 实现页码切换与直接下载。
